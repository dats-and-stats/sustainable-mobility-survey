# sustainable-mobility-survey

This repository contains the data and replication materials for the paper:  
**"Sustainable mobility tools and perceived risk: a SEM-based survey in an Italian metropolitan area"** (by Simona Balzanno, Houyem Demni, Luisa Natale, Edoardo Pascucci, Giovanni C. Porzio)

## Repository Structure
* `dataset_clean.csv`: Raw survey responses (N = 1003) used in the Structural Equation Modeling (SEM), anonymized.
* `codebook.xlsx`: Description of survey items and variable names.
* `PLS-SEM-mobility-github.R`: R script used to perform the Structural Equation Modeling (SEM).
